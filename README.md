
# 📱 Best Mobile Care – Mobile Repairing Center Website

A **fast, fully responsive, modern mobile repairing center website** built using **Next.js**, **Tailwind CSS**, and **Shadcn UI**, designed with **pastel yellow & golden yellow HSL color palettes**, **dark/light mode**, and **English/Nepali translations**.

This project is optimized for **speed, SEO, and mobile-first experience**, suitable for real-world business use.

---

## 🌐 Live Overview

**Business Name:** Best Mobile Care
**Service Type:** Mobile Repairing Center
**Location:** Kathmandu, Nepal
**Default Language:** English (Nepali supported)
**Theme:** Light / Dark Mode

---

## 🛠 Tech Stack

| Technology       | Usage                                 |
| ---------------- | ------------------------------------- |
| **Next.js**      | App Router, SSR, SEO, Performance     |
| **Tailwind CSS** | Utility-first styling                 |
| **Shadcn UI**    | Accessible, modern UI components      |
| **Clerk Auth**   | Authentication & user management      |
| **MongoDB**      | Authentication & data storage         |
| **TypeScript**   | Type safety                           |
| **HSL Colors**   | Pastel yellow & golden yellow palette |
